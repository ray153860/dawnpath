# 代码导览

从 `src/main.tsx` 开始：它把 React 应用挂载到 `index.html` 的 `root` 节点。`src/App.tsx` 管理页面切换、问卷草稿、体验记录、历史记录和导入导出。`src/style.css` 负责布局、颜色、响应式及减少动态效果。

## 一次测评怎样产生报告

1. `src/questionBank.ts` 定义题目、学科、活动维度和题库版本。题目文本不写在评分函数里。
2. 用户在 `App.tsx` 选择 0–4 分或“信息不足”。未回答保留为空；两者都不会被当成 0 分。
3. `src/assessment.ts` 分别整理学科主题与活动回答，并保留体验反馈的来源和数量。它不计算专业匹配率。
4. 保存测评时，记录题库版本和当时的回答快照。报告读取该快照，避免以后修改草稿时改变历史结果。
5. 数据留在浏览器 `localStorage`。导出的 JSON 可用来恢复；清除前应先导出备份。

## 建议的学习顺序

先运行 `npm ci` 和 `npm run dev`，在浏览器里完成一次测评。接着阅读 `questionBank.ts` 与 `assessment.ts`，观察一条回答如何变成报告中的证据状态。最后改一个页面文案或样式，运行 `npm test`、`npm run lint` 和 `npm run build`。

若要增加题目，先确定它测的是学科内容、活动方式还是体验后的感受，再给它稳定 ID 和来源记录。修改计分逻辑时，先写出缺失、未知和明确不感兴趣各自应怎样显示，再补对应测试。不要把未经验证的新权重称为科学结论。

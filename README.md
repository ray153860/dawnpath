# DawnPath（曙光）

兴趣不是一次选择，而是一段探索。DawnPath 是一个开源、中文优先、无需注册的跨学科兴趣探索原型。测评内容为原创情境，不构成心理诊断、能力测验或职业建议。当前评分权重属于未经验证的产品假设。

## 开始

```sh
npm install
npm run dev
```

## 构建与预览

```sh
npm run build
npm run preview
```

输出位于 `dist/`，可部署到支持静态 HTML 的托管服务或 ModelScope Static Space。所有数据存储在浏览器 localStorage；可从“我的足迹”导出、恢复或清除。请勿在共享设备上保存敏感信息。

## 页面与当前范围

- 首页、学科地图、情境测评、学科自评、探索报告、学科体验、我的足迹。
- 12 个学科方向；情境题与体验任务采用数据驱动结构。
- 24 道独立情境题每题有四个学科方向；12 学科在题目中均衡出现。用户可选首选、次选、都感兴趣、都不感兴趣、信息不足或跳过。
- 每个学科有一个可提交判断和兴趣反馈的微型任务。题目与任务尚未经学科专家或测量学验证。
- 情境、主题和体验兴趣分别处理；体验后指标在完成两个不同学科任务后启用。活动偏好独立展示，不进入学科分数。
- 当前版本使用 localStorage。后续可迁移 IndexedDB，并提供版本化迁移。报告和记录尚未提供完整历史对比图。

## 测试

```sh
npm test
npm run lint
```

评分测试覆盖题目学科分布、活动维度分布、缺失数据和体验后权重。部署静态站点时请上传 `dist/` 中的内容，入口文件需位于空间根目录；页面在单页内切换，不依赖服务端路由重写。

## 贡献

欢迎提交题库、无障碍和多语言改进。新增测评内容需说明设计依据、覆盖范围与限制；不得声称科学准确率、天赋分或录取/职业概率。

# DawnPath（曙光）

兴趣不是一次选择，而是一段探索。DawnPath 是中文优先、无需注册的跨学科兴趣探索网站。当前版本是**未经心理测量验证的探索原型**，不提供人格类型、专业匹配率、职业适合概率或能力判断。

在线体验：[ModelScope 创空间](https://modelscope.cn/studios/shanshanshu/dawnpath)。

## 运行

需要 Node.js 与 npm。

第一次阅读代码可从 [代码导览](docs/代码导览.md) 开始。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

静态构建产物位于 `dist/`。ModelScope Static 空间需将其中的全部文件放在站点根目录。页面切换采用单页状态，不需要服务端路由重写。

## 功能与数据

- 首页、学科地图、兴趣探索、报告、12 类学科体验、我的足迹。
- 已停用旧版 24 道跨学科情境题。新版题库位于 `src/questionBank.ts`，有来源、许可与版本标记；研究档案见 [题库研究与测评方案](docs/题库研究与测评方案.md)。
- 学科主题、活动方式与体验反馈分开呈现。12 个学科各只有一题，因此结果只是当前自评线索。报告不将缺失信息记为零。
- 进度与历史保存在浏览器 `localStorage`。可在“我的足迹”导出、恢复和清除 JSON。旧版数据仍可读取，但旧情境答案不再计分。
- 当前没有账号或云端数据同步；同一浏览器中的数据清除后只能通过事先导出的 JSON 恢复。

## 测试

```sh
npm test
npm run lint
npm run test:e2e
```

单元测试覆盖题库版本、缺失与无效值、学科与活动分开计算。端到端测试覆盖测评、报告、重测、体验与刷新保存。Playwright 当前使用本机 Microsoft Edge；如本机没有 Edge，可调整 `playwright.config.ts`。
